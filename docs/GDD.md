> 작성일 2026-10-23 · 상태: 프로토타입 단계
> 이 문서는 확정 사항과 미정 사항을 구분해 관리한다. 미정 항목은 ⏳ 표시.

## 1. 한 줄 컨셉

거점을 선으로 이어 병력을 흘려보내는 **땅따먹기 전략**에, **영웅·장비·유물 성장**과 **도시 → 프로빈스 → 국가 캠페인**을 얹은 하이브리드 캐주얼 게임.

- 레퍼런스: Tower War, State.io, Mushroom Wars, 스타크래프트2 유즈맵 "땅따먹기", 탕탕특공대(로비 구조), EU4(캠페인 맵 감각)
- 플랫폼: HTML5(웹) 개발 → Capacitor로 Android 앱 변환 → AdMob 연동
- 수익: 광고(보상형 중심 + 판 사이 전면) + 인앱 결제(스킨)

## 2. 배경과 세계관

- **가상 대륙의 중세 판타지.** 실제 지도는 쓰지 않는다(정치 리스크 회피).
- 국가마다 실제 문화권 모티브: 유럽풍 왕국, 동양풍 제국, 사막 술탄국, 북방 부족 등 → 국가별 맵 분위기·영웅·스킨 차별화
- 최종 적: **암흑군단**(절대악). 보스전에 강력한 영웅 유닛 등장
- 아트: 밝고 둥근 플랫 스타일, 암흑군단 지역만 어둡게 대비
- 확장 여지: 행성/우주 챕터는 후속 콘텐츠(암흑군단 이후 새 위협) ⏳

## 3. 캠페인 구조

```
도시(전투 1판) → 3~5개 점령 = 프로빈스 → 5~10개 프로빈스 = 국가 → 보스(암흑군단)
```

- 국가 1개 = 전투 약 15~50판
- 적도 프로빈스·국가 단위로 강해짐(영구 성장으로 인한 난이도 붕괴 방지)
- 판 바깥 구조로 로그라이트 런 방식도 후보 ⏳

## 4. 전투 시스템

### 4.1 기본 흐름
1. 베이스가 **분당 자원**을 생산하고, 자원이 유닛 생산 비용에 도달하면 유닛 1명 생산
2. **내 노드 탭(선택) → 인접 노드 탭**하면 선이 이어지고 자동 이동 시작(노드당 출발선 1개)
3. **선을 탭하면 끊김.** 노드 선택 시 하단 패널에서도 끊기 가능
4. 루프 방지: 반대 방향으로 이으면 방향 전환, 3개 이상 노드의 순환 경로는 연결 거부
5. 하단 노드 패널: 주둔 병종 수, 생산 병종 선택(베이스), 병종별·영웅 출격 토글, 연결 상태
6. 유닛은 한 명씩 실제로 존재하며 선 위를 이동
7. 적 노드에 도착하면 전투, 수비 병력이 0이 되면 점령

### 4.2 전투 공식 (초안)
- 피해 = `max(1, 공격력 − 방어력)`
- 유닛마다 HP 보유
- 수치는 튜닝 패널로 조정하며 확정 ⏳

### 4.3 노드(건물) 종류

| 노드 | 역할 | 비고 |
|---|---|---|
| 베이스 | 자원 생산 → 유닛 생산. 탭하면 생산 병종 전환 | |
| 타워 | 주둔지·전초기지. 수용 인원 큼 | |
| 요새 | 보유 시 팀 전체 방어력 +1 | (기존 명칭 "거점"에서 변경) |
| 포탑 | Lv1~3, 주변 선을 지나는 적에게 피해(1/2/3) | 효과·작동 방식 개발 중 변경 예정 ⏳ |
| 트랩 | Lv1~3, 주변 적 방어력 −1/−2/−3 | 포탑과 운영 방식 동일 ⏳ |
| 관문(성문/다리) | 주둔 가능, **최소 주둔 인원** 유지. 통과하는 아군은 그대로 지나감. 수비가 0이면 함락 | 길목 역할 |

### 4.4 유닛
- 모든 일반 유닛은 같은 유닛으로 시작, **유닛 레벨은 전체 공유**
- **무기 슬롯 3개**: 탱커 / 근거리 / 원거리 → 어떤 무기를 전장에 가져가느냐로 병종 구성 결정
- 전투 중 생산 병종은 **베이스 선택 후 하단 패널에서 선택**(베이스마다 1병종)
- 상성: 탱커(HP 높음, 근거리 저지) / 근거리(공격력 높음, 원거리 제압) / 원거리(접촉 전 선제 사격, 탱커 깎기)
- 해금: 근거리 → 원거리(프로빈스 1 클리어) → 탱커(프로빈스 2 클리어)
- 화면 표시: 노드 안 숫자 + 병종 비율 표시

### 4.5 영웅
- 한 판에 **최대 3~5명**, 프로빈스 진행에 따라 슬롯 **단계적 해금**(1명 시작)
- 영웅끼리는 **영웅 레벨 + 고유 스킬**로 차별화
- 장비·도구·유물 레벨은 영웅 전체 공유(일반 유닛과는 별도 트리)
- 등급(일반/희귀/영웅/전설)은 스킬 강도로 구분
- 랜덤 뽑기 판매 시 국내 확률형 아이템 확률 공개 의무 → 광고 뽑기·확정 구매 우선 검토 ⏳

### 4.6 AI
- 성격 부여: 돌격형 / 수비형 / 기회주의형
- **3자 이상 난전**(AI끼리도 싸움)으로 같은 맵에서도 매번 다른 전개

## 5. 화면 구조 (탕탕특공대식 로비)

```
[로그인/타이틀] → [로비]
                   ├ 상단: 프로필·레벨 / 골드 / 보석 / 행동력
                   ├ 중앙: 현재 챕터(국가·프로빈스·도시 진행도), [전투 시작]
                   └ 하단 탭 5개
                      상점(뽑기) | 군단(영웅·유닛·장비·유물·룬) | 전투(기본) | 아레나 | 클랜(소셜)

[전투 시작] → [전투] → [결과: 보상, 광고 보고 2배 / 패배 시 광고 보고 이어하기] → [로비]
```

| 탭 | 내용 | 개발 시점 |
|---|---|---|
| 전투 | 캠페인 지도, 도시 선택, 전투 진입 | 프로토타입 |
| 군단 | 영웅 목록, 무기 3슬롯, 장비·유물·룬 강화, 스킨 | 버티컬 슬라이스 |
| 상점 | 뽑기, 스킨, 광고 보상 | 버티컬 슬라이스 |
| 아레나 | **비동기 PvP**: 다른 유저의 덱을 AI가 조종. 실시간 서버 불필요 | 본 제작 |
| 클랜 | 친구·클랜. 서버(예: Firebase) 필요 | 출시 후 ⏳ |

## 6. 수익 구조

| 위치 | 형태 |
|---|---|
| 판 클리어 후 | 전면 광고(빈도 제한) |
| 결과 화면 | 보상형: 보상 2배 |
| 패배 시 | 보상형: 이어하기 |
| 보스전 전 | 보상형: 영웅 슬롯 +1 |
| 상점 | 보상형 뽑기, 스킨 인앱 결제 |

## 7. 기술 원칙

- HTML5 Canvas, 세로(9:16) 화면 기준
- 설치 용량 목표 30~80MB: 이펙트는 코드 파티클, 스킨은 팔레트 스왑+파츠, 배경은 타일 조합, 추가 콘텐츠는 서버 다운로드
- **RAM 기준: 한 판에 올라가는 그래픽 메모리 150MB 이하**, 판 단위로 리소스 로드·해제
- 테스트 기준 기기: 2~3년 된 보급형 폰
- 개발 중 광고는 **테스트 광고 ID만** 사용

## 8. 개발 단계

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| 1. 컨셉 | 본 문서 | ✅ |
| 2. 프로토타입 | 원·선·숫자만으로 한 판의 재미 검증 + 로비 흐름 | 10판 해도 재밌음 ← **현재** |
| 3. 기획서 확정 | 수치·성장 곡선·화면 흐름 | 제작 목록 확정 |
| 4. 버티컬 슬라이스 | 프로빈스 1개 완성도 있게(아트·연출·성장·광고) | |
| 5. 본 제작 | 콘텐츠 양산, 아레나 | 알파 → 베타 |
| 6. 소프트 런칭 | 일부 국가 출시 | D1 리텐션 35~40% 목표 |
| 7. 출시·라이브 운영 | 이벤트, 신규 영웅, 시즌 | |

## 9. 프로토타입 v0.1 범위

- 로비(하단 5탭, 전투 탭만 동작, 나머지는 구조 확인용 목업)
- 프로빈스 1개 = 도시 3개(맵 3종), 진행도 저장
- 노드: 베이스 / 타워 / 요새 / 포탑 / 관문
- 병종: 근거리 / 원거리 (베이스 탭으로 전환)
- 영웅 1명(스킬: 돌격 함성)
- AI 2명(돌격형·수비형) 3자 난전
- 결과 화면(광고 버튼은 목업)
- 튜닝 패널: 자원 생산 속도, 유닛 수치 실시간 조정
